# Modifier Set — 20 MVP cells (FINAL, founder-locked)

The state-image suffix for each cell's headline. Rides as ONE phrase with the archetype name
(e.g. "MATAHARI yang Teduh", "AKAR Kusut Melilit"). The picture encodes the element-state; the
mechanics word (Balanced/Amplified) NEVER appears in a headline. Card rule 3 / interpreter §3.

Balanced = the element at rest / at home (full, steady, nothing extreme).
Amplified = the element flooding its OWN nature (too much of itself, the shadow edge).

## Reading-direction notes (how the modifier sets the reading's tone)
The modifier is the FIRST promise the reading makes. The beats must pay it off:
- **Balanced modifiers** name a settled strength -> the reading flatters the gift, then reveals its
  quiet cost (the unthanked side). The Ache is the cost of the steady virtue.
- **Amplified modifiers** name the flood/shadow -> the reading still opens warm (card flatters), but
  the driver (beat 3) is the element overflowing its banks. The modifier is the hook the beat-3
  reveal explains. e.g. "Kusut Melilit" -> beat 3 reveals the vine adapted so far it lost its own shape;
  "Pasang Raya" -> the tide with no shore to hold it; "Melalap Sumbu" -> the flame eating its own wick.

## Pairings worth carrying into prose (the image is already chosen, match the metaphor)
- Matahari: Teduh (shaded warmth) / Puncak Siang (noon glare, nowhere to hide)
- Pelita: Pijar Setia (faithful steady glow) / Melalap Sumbu (devours its own wick)
- Gunung: Berpijak Kokoh (firmly grounded) / Menjulang Sunyi (towers into isolation)
- Ladang: Subur Bersemi (fertile, blooming) / tanpa Pagar (field with no fence)
- Pedang: Terhunus Siaga (drawn, ready, calm) / Selalu Terasah (honed past need, cuts at nothing)
- Permata: Berkilau Cemerlang (brilliant, refined, secure) / tanpa Cela (polished past any standard, never done)
- Samudra: Berarus Dalam (calm surface, deep current) / Pasang Raya (high tide, no shore)
- Hujan: Rintik Lembut (gentle drizzle, soaks in) / Tak Reda (rain that won't stop, rises)
- Jati: Berbatang Tegak (tall, straight trunk) / Kaku Getas (so rigid it's brittle, breaks not bends)
- Akar: Menjalar Luwes (winds supple around obstacles) / Kusut Melilit (tangled, strangles its own shape)
