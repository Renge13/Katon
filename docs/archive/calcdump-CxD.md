# RAW BAZI DUMP — Orang C & Orang D (+ compatibility)

## ORANG C — 6 Juni 1992, 07–09 pagi (jam Naga 辰)
Pilar (batang langit + cabang bumi):
  Tahun: 壬申 | batang 壬 = Air Yang [Ten God: Jie Cai / Perebut-rival] | cabang 申 = Logam (Monyet); tersembunyi 庚Logam, 壬Air, 戊Bumi
  Bulan: 丙午 | batang 丙 = Api Yang [Ten God: Zheng Cai / Nafkah]      | cabang 午 = Api (Kuda); tersembunyi 丁Api, 己Bumi
  Hari : 癸丑 | batang 癸 = Air Yin  [= DIRI / Day Master]              | cabang 丑 = Bumi (Kerbau); tersembunyi 己Bumi, 癸Air, 辛Logam
  Jam  : 丙辰 | batang 丙 = Api Yang [Ten God: Zheng Cai / Nafkah]      | cabang 辰 = Bumi (Naga); tersembunyi 戊Bumi, 乙Kayu, 癸Air
Day Master: 癸 = Air, Yin.
Elemen (total 8.0): Kayu 0.30 (4%) | Api 2.60 (32%) | Bumi 1.70 (21%) | Logam 0.70 (9%) | Air 2.70 (34%)
Penopang DM (Air): Air + Logam(pengasuh) = 3.40/8 = 42%.
Menopang DM: Air, Logam. Menguras/menekan DM: Kayu (output/karya), Api (harta), Bumi (pengendali).
Kekuatan DM: SEIMBANG. Terbanyak: Air (34%) & Api dekat (32%). Tidak ada elemen kosong.
Musim lahir: cabang bulan 午 = Api.
AKAR DM: Air berakar di TIGA cabang (申 tahun, 丑 hari, 辰 jam menyimpan 壬/癸 Air). DM ini berakar kuat — tidak mengambang.
Kursi pasangan (cabang Hari) = 丑 Bumi (Kerbau). Batang tersembunyi utama 己 → thd DM = Qi Sha (Tekanan).
  Relasi cabang 丑: bentrok 未(Kambing) | gabung 子(Tikus) | harm 午(Kuda).
Catatan penting untuk hirarki: dua unsur hampir seimbang di puncak (Air 34% / Api 32%) — Api adalah
  "harta" (Zheng Cai, muncul DUA kali di batang Bulan & Jam). DM Air seimbang & berakar tiga. Kursi
  pasangan = Bumi/Tekanan (Qi Sha). Ini chart yang jauh lebih seimbang daripada chart ekstrem —
  jangan paksakan drama; pimpin dengan yang paling menonjol (Api-harta ganda + akar Air kuat).

  Jam  : 己未 | batang 己 = Bumi Yin [Ten God: Jie Cai / Perebut]   | cabang 未 = Bumi (Kambing); tersembunyi 己Bumi, 丁Api, 乙Kayu
Day Master: 戊 = Bumi, Yang.
Elemen (total 8.0): Kayu 1.10 (14%) | Api 2.00 (25%) | Bumi 3.60 (45%) | Logam 0.30 (4%) | Air 1.00 (12%)

Menopang DM: Bumi, Api. Menguras/menekan DM: Logam (output), Air (harta), Kayu (pengendali/tekanan).

  ditopang. Kursi pasangan = sesama Bumi (Bi Jian) → menarik pasangan yang seperti dirinya/mandiri.

## KECOCOKAN C × D
Day Master: C 癸 Air × D 戊 Bumi. Relasi elemen: BUMI MENGENDALIKAN AIR → D menekan/membendung C.
  (Ten God: batang D thd C = Zheng Guan / Wibawa; batang C thd D = Zheng Cai / Nafkah.)
  Catatan: 癸(Air) dan 戊(Bumi) adalah pasangan kombinasi batang klasik (戊癸合) — tarikan langsung,
  polaritas berlawanan. Bendungan (Bumi menahan Air) bisa berarti struktur & rasa aman, bukan hanya tekanan.
Kursi pasangan: C 丑 (Kerbau, Bumi) × D 戌 (Anjing, Bumi) → NETRAL antar-kursi (tidak bentrok/harm/gabung
  langsung). Keduanya cabang Bumi — fondasi rumah tangga cenderung stabil, tanpa gesekan seat bawaan.
Pertukaran elemen (C% | D%): Kayu 4|14 · Api 32|25 · Bumi 21|45 · Logam 9|4 · Air 34|12.
  C DM Air (seimbang, berakar); D DM Bumi (kuat, berakar).
  C butuh: Air + Logam. C terkuras oleh: Kayu, Api, Bumi.
  D butuh: Bumi + Api. D terkuras oleh: Logam, Air, Kayu.
  Pertukaran: C kaya Air (34%); D kekurangan Air (12%) → C bisa menyuplai Air ke D (harta D). D kaya
  Bumi (45%); Bumi menekan Air C → kehadiran D membendung/menstrukturkan C. Arahnya lebih dua-arah &
  seimbang daripada pasangan A×B sebelumnya: C bukan DM lemah, jadi bendungan Bumi tidak langsung
  menghabisinya — bisa terasa sebagai batas/keamanan, bukan pengurasan total. Tetap jujur: terlalu
  banyak Bumi tetap bisa terasa mengekang bagi Air yang ingin mengalir.
Cuaca waktu (individual triggers): kursi C 丑(Kerbau) bentrok 未(Kambing); kursi D 戌(Anjing) bentrok
  辰(Naga). CATATAN RELASIONAL: kursi C & D TIDAK saling bentrok/harm/gabung → tidak ada pemicu waktu
  yang murni relasional. Sesuai aturan: JANGAN tempel dua trigger solo ke bagian kecocokan; boleh
  disebut ringan di bacaan individu masing-masing, tapi bukan fakta pasangan.
