# Batch-Write Worksheet — 20 MVP cells (Balanced + Amplified × 10, Hubungan)

The grind protocol. One cell = fill the INPUTS block from the three reference tables, then prose to
the locked template. Write to the v5.2 baku voice from the start (do NOT port v5.1 prose — mine the
old readings for strong IMAGES only, never sentences). Output shape = `lib/content/matahari.js`.

## Order of operations per cell
1. **Fill INPUTS** (5 min, pure lookup — no writing). Pull from DRIVER-MATRIX-50, modifier-set,
   feed-drain-lookup. If any input is blank you are not ready to prose.
2. **Check collapse-flags** against already-written cells (don't ship two cells with the same driver).
3. **Prose to template** — Claude writes structural scaffold (beats/meaning/boundary locked, Indonesian
   flagged not-final) → helper naturalizes → founder validates voice/meaning.
4. **QA gate** (the locked checklist, bottom of this doc) before marking done.
5. **Register** one line in REGISTRY.

### Boundary discipline (the rule that earns the Rp 49K)
- FREE river: names the SYMPTOM + ends on "and you don't know why" (open loop). NO driver, NO cause-list,
  NO signature metaphor. (These three are paid-beat-3-exclusive.)
- PAID beat 3: owns the driver + the cause + the signature metaphor. Opens straight into the reveal.
- Beat 1 validates something the FREE read did NOT say (usually the unthanked COST of the gift).
- Amplified cells: the MISSING/flood element is the beat-3 reveal — withhold it from free entirely.

### Voice discipline (v5.2 baku — §8)
- Polished baku, "kamu", warm-composed. NO slang in brand prose (ngerasa/bikin/kayak/capek/rame).
- Inner voice ONLY (bridge + beat6 rule) stays conversational — it's her, not the brand.
- NO "bukan X, (tapi/justru/melainkan) Y" skeleton. Contrast by CONCESSION ("Bisa jadi... padahal...").
- NO em-dash. NO connective openers (Maka/Tapi/Justru/Di situ). Consequence-first ordering.
- Metaphors must land on first read. No mystical set (alam semesta/energi/takdir/ramalan/aura).
