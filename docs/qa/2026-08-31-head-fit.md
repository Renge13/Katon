# Head fit at 1080x1350 — the real-fit gate, measured

## The question

Prompt R section 0a, ruled by Reyner 2026-08-31:

> Replace the word-count `x 0.80` branch with a real-fit gate. Embun remains at 139 on the new 936px
> measure unless the rendered text actually fails to fit.

The branch being replaced was `head.length > 1 ? sc.headline * 0.80 : sc.headline` — a proxy for
"this might be too wide".

## Method

`scripts/measure-head-fit.mjs`. Headless Chromium over CDP, no new dependency. Every head word of
every archetype rendered at the card's own declarations, read from the same exported constants
`<Headline>` uses (`HEADLINE_SIZE`, `HEADLINE_WEIGHT`, `HEADLINE_TRACKING`) so the ruler and the card
cannot disagree. `document.fonts.check('800 139px Archivo')` must return true or the script refuses
to print anything — a width measured in a fallback font is a confident number about a font the card
does not use.

**Words, not phrases.** `<Headline>` renders `head.map(w => E('div', {}, w))`, so each word gets its
own block and its own line. A multi-word head never has to fit on one line; only its longest word is
ever constrained.

## The finding: the proxy was backwards in both directions

The old measure was `907 - 2 x 72 = 763`, from the constants at `0c1ac73`.

| | width | old measure 763 | what the proxy did |
|---|---|---|---|
| **MOUNTAIN** (戊) | 793.48 | **OVERFLOWED by 30.48px** | nothing — one word, so full size |
| **MORNING** (癸) | 716.80 | fit, 46.20px spare | **reduced to 0.80** — two-word head |

**The rule shrank the word that fit and clipped the word that did not.** MOUNTAIN is 8 characters
and MORNING is 7, so the proxy was not even monotonic in the thing it stood for.

The clip is not hypothetical: the object declares `overflow: hidden`, so a 793.48px word inside a
763px content box loses its right edge. 戊 is a shipped archetype on the free share card.

**Both are resolved by this commit** — not by a fix aimed at either, but because the measure went to
936 and the gate now asks about fit. MOUNTAIN has 143px spare; MORNING renders at full 139.

## What is pinned, and what is not

`HEADS_THAT_OVERFLOW` in `components/cards/Card.js` is **empty**, and the branch **stays**. §0a is
explicit that it is the gate for a future name that genuinely overflows; only its trigger moved.

The set being empty means every assertion about the ten passes whether the branch works or not, so
`tests/card.spec.mjs` exercises the predicate directly on a synthetic pinned head. A gate that cannot
be observed firing is not a gate.
