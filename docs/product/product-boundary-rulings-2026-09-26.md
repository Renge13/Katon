# Product boundary rulings, 2026-09-26 (Reyner)
STATUS: RULED by Reyner (chat, 2026-09-26; items 5, 6 and 9 amended by him later the same day for the MVP), after Cowork's pressure test against the repo and `reports/architecture-cost-2026-09-26.md` (Prompt AF).
**This confirms, and does not replace:**
- PROGRESS "PRODUCT / FUNNEL — DECIDED";
- `docs/product/paid-product-map.md` § RULED 2026-08-29;
- the 2026-08-12 ruling that rules out the free half-mirror.

**The core model:** one canonical reading. Free proof. Paid ownership. Paid relationship exploration.

1. **The free Mirror stays fully free.** It is the whole Katon reading on the web, never a shortened teaser. The interpretation is never sold back. Mirror = Recognition / proof; Complete Edition = Ownership; Compatibility = Curiosity / relationship.
2. **One canonical AI reading; never render twice.** One birth-data submission produces one validated reading. That reading powers the free web Mirror, the Complete Edition PDF and Card B. The CE never asks the writer for a second version. Its value is the artifact, permanence, aesthetics and reference material. (Today: `lib/deliver/handlers.js` prints the cached render; no second writer call exists.)
3. **Compatibility appears at the curiosity moment.**
   - A Compatibility CTA goes on the Mirror result page, shown only while payments are open.
   - The journey: "This is me" → "I wonder about someone else" → Compatibility.
   - The result page is never a product grid.
   - One CTA per moment: CE at the "keep/share this" moment, Compatibility at the "what about us?" moment.
   - Its absence today is a funnel defect, not a strategy question.
4. **CE is not bulked up pre-emptively.** Its boundary stays: the PDF, the premium Card B, and the chart/reference appendix. Conversion data decides whether that is enough. A conversion problem is never solved by making the free Mirror incomplete.
5. **MVP render path (amended by Reyner later on 2026-09-26; this replaces "option D"):** BaZi engine → Flash-lite writer → deterministic truth, safety and document checks → serve.
   - No semantic judge in the production render path, neither Pro nor Flash-lite. The judge (`lib/validate/judge.js`, `scripts/calibrate-j1.mjs`) stays only as a development/QA tool for sampled calibration. It never runs on a user's reading.
   - Flash-lite is the MVP writer. There is no writer-model bake-off.
   - Engine-provable errors get hard deterministic checks on v1 and v2: pair direction and supplier, cross-chart/day-seat relations, element dominance.
   - **Engine accuracy is non-negotiable; interpretive prose can be bold and confident.** The prose must not feel audited sentence by sentence.
   - A stronger writer or a production judge returns only on post-launch evidence that a problem affects customers or revenue.
6. **Model spend stays bounded.** With no production judge there is no judge spend in the render path, so the writer's daily ceiling bounds it. Any QA judge run is manual and outside user traffic.
7. **Free usage and abuse are a separate problem.** Inference economics are never solved by shrinking the free reading. The fix is abuse protection: abuse limits, ceiling sizing, no single actor consuming the shared budget, and genuine users not all being sent to the fallback when the budget runs out.
8. **These v2 defects block launch:**
   - Cached v2 readings are validated with the rules of the voice that generated them.
   - The v2 pair badge check never rejects a badge the engine supplied.
9. **Voice stays launch-critical.** The launch sequence lives in `docs/content/voice-constraint-rulings-2026-09-26.md` (STATUS): frame-hit truth fix → Reyner's examples → simplify constraints → deterministic validation updates → representative test → Reyner's acceptance → launch. The DOKU production gate is independent. There is no model bake-off and no semantic-judge checkpoint. Katon does not launch on v1 because DOKU is ready. Every stale "launch on v1" / "VOICE V2 PARKED" reference is corrected.
10. **The future conversational product stays open.** The product stays reading/PDF based. The direction to preserve: free Mirror → trust → another person → Compatibility / CE → eventually paid conversational exploration. The canonical reading must stay useful as the first turn of a future conversation. Nothing is redesigned around chat yet.
