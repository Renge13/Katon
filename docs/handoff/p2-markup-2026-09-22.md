## D. What this markup does NOT touch

fails on today's PDF first. LAYOUT rows are round 1 too if Reyner marks ok, else round 2. COPY rows (A1 name,
A2 format, A3 order, A6 names) need Reyner's words before Code touches them; until then they ship as
`PENDING()` and the production build refuses, which is correct.
