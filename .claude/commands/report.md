Summarise what you just did, in this shape:

1. **What changed**, with commit hashes, engine and calibration separated.
2. **Before/after numbers** for every metric you touched. Include the ones that did NOT move.
3. **Anything that contradicted the docs.** Name the file and the line. Four spec errors have been
   caught this way and every one mattered.
4. **Anything you declined to do**, and why. Declining to bank a tempting parameter has been the right
   call twice.
5. **The one thing you need a ruling on**, if any. One, not five.

Then propose the update for the MEASUREMENTS table in `docs/PROGRESS.md` — do not edit `CLAUDE.md`.
